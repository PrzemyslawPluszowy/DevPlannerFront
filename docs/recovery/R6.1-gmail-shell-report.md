# R6.1 — desktopowy shell Gmail-like

Data: 2026-09-17  
Repozytorium: `Front`  
Zakres: nowy shell desktopowy; bez zmian Backend, Chat/Notifications i
legacy `workspaces_home`.

## Wynik

Przejściowy `NavigationRail` został zastąpiony shell’em z trzema małymi
plikami odpowiedzialności:

- `lib/app/shell/devplanner_shell.dart` — właściciel lifecycle Cubita i stanu
  zwinięcia;
- `lib/app/shell/devplanner_shell_layout.dart` — layout topbara, sidebara i
  canvasu;
- `lib/app/shell/devplanner_shell_navigation.dart` — renderowanie clean drzewa,
  etykiet ARB, ikon semantycznych i tylko dozwolonych tras.

Topbar ma stałe 64 px i własną zarezerwowaną przestrzeń. Sidebar ma 256 px w
trybie rozwiniętym oraz 72 px po zwinięciu, niezależny `SingleChildScrollView`
i lokalny przycisk zwijania. Dla mniejszych desktopowych szerokości (<960 px)
przechodzi automatycznie w tryb 72 px, żeby content zachował użyteczną szerokość.

Content otrzymuje 12 px marginesu, semantyczne `ColorScheme.surface` oraz
centralny zaokrąglony `Material` z promieniem 20 px. Wszystkie kolory pochodzą
z `Theme.of(context).colorScheme`, więc ten sam layout obsługuje jasny i ciemny
motyw bez osobnych wartości kolorów.

Sidebar korzysta bezpośrednio z `WorkspaceNavigationTreeCubit`; nie zawiera
HTTP, DTO, routingu biznesowego ani danych zastępczych. Gdy clean porty nie są
dostarczone, pokazuje jedynie zlokalizowany stan niedostępności. Błąd listy
projektów nie jest zamieniany w częściowy/fallback snapshot.

W drzewie klikalne są wyłącznie istniejące trasy: `/workspaces` (Overview),
`/me` (ustawienia profilu) i `/admin` (administracja). Workspace, projekt oraz
zasoby projektu są nieklikalne do czasu powstania ich realnych tras. Chat i
Notifications nie mają w tym pakiecie żadnych kontrolek ani paneli.

## Zmienione pliki

- `lib/app/shell/devplanner_shell.dart`
- `lib/app/shell/devplanner_shell_layout.dart`
- `lib/app/shell/devplanner_shell_navigation.dart`
- `lib/app/router/devplanner_router.dart` — jawne wstrzykiwanie clean
  `WorkspaceNavigationGateway`/`ProjectsGateway` oraz produkcyjne adaptery z
  aktualnego transportu.
- `test/app/shell/devplanner_shell_test.dart` — geometria, zwijanie,
  persystencja zaznaczenia/treści po nawigacji i render clean drzewa.

Każdy widget mieści się poniżej 400 linii (74 / 202 / 293). Nie zmieniano
legacy `workspaces_home`, root route definitions ani Backend. `NavigationRail`
nie występuje w nowym shellu.
